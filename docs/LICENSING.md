# Licensing

**Goal: free for developers and the public good, paid for companies.**

FreeSaaS uses the **Business Source License 1.1 (BSL)**
([LICENSE](../LICENSE)), the same model used by MariaDB, CockroachDB and
Sentry.

| Who | Cost |
|---|---|
| Anyone developing, testing, evaluating or demoing | Free |
| Individuals, for personal or non-commercial use | Free |
| Non-profits, charities, schools and universities | Free |
| Companies running it in production | Commercial license |
| Anyone offering it as a hosted service to others | Commercial license |

Each version automatically becomes **Apache-2.0 four years** after its
release, so the code always ends up fully open.

## Things to know

- **BSL is "source-available", not OSI "open source".** Anyone can read,
  modify and contribute to the code, but some people and programs only work
  with OSI-approved licenses. For example, some public grants (such as
  NLnet/NGI) require one. If grants become central to funding, consider
  dual-licensing AGPL-3.0 plus a commercial license instead.
- **The editors are not covered.** `upstream/` stays MIT OR Apache-2.0.
  Companies can always use WordCraft, GridCraft and DeckCraft directly for
  free. What they pay for is the FreeSaaS suite: connectors, hub, interop,
  deployment and support.
- **Contributions need a CLA**, so the project can grant commercial licenses
  that cover community-contributed code. See
  [CONTRIBUTING.md](../CONTRIBUTING.md).
- **Open decisions:** whether small companies (for example, under 10
  employees) should also be free; the Licensor legal entity; pricing. Have a
  lawyer review before the first public release.
